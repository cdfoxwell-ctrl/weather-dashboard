# Weather Dashboard

A responsive weather dashboard that fetches real-time weather data from the OpenWeatherMap API.

## Features

- 🌍 **Search by City** - Look up weather for any city in the world
- 📍 **Geolocation** - Get weather for your current location
- 🌤️ **Current Weather** - Temperature, humidity, wind speed, pressure, and more
- 📅 **5-Day Forecast** - See weather predictions for the next 5 days
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile
- ⚡ **Real-time Updates** - Fresh data from OpenWeatherMap API

## Setup

1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Open `script.js` and replace `const API_KEY = 'demo'` with your actual API key
3. Open `index.html` in your browser

## Weather Data Provided

- Current temperature (feels like)
- Humidity percentage
- Wind speed
- Atmospheric pressure
- Visibility distance
- UV index (cloud coverage)
- 5-day weather forecast

## Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript
- OpenWeatherMap API
- Geolocation API
